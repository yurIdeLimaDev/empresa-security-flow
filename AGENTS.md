# Consulta de conhecimento do projeto

Para perguntas sobre a arquitetura, fluxos, políticas, decisões, ferramentas,
evidências ou validações deste repositório, consulte primeiro o MCP
`project_knowledge` pela ferramenta `search`. Formule a resposta a partir dos
trechos retornados e cite os caminhos-fonte.

Não faça varredura recursiva nem leia arquivos do projeto antes dessa consulta.
Abra um arquivo somente quando o índice declarar insuficiência ou quando for
necessário confirmar código, configuração ou evidência exatos. O índice não
inclui `correcao/casos/`, binários, caches ou a landing page React; para esses
escopos, explique a limitação antes de abrir arquivos.
